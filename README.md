## 🚀 Proyectos Destacados

He estructurado el repositorio en directorios temáticos. Estos son los proyectos que mejor reflejan mi capacidad técnica:

### 1. 📊 Inteligencia Artificial y Análisis de Datos
*   **`algoritmos_aprendizaje_Weka_Python_Jupyter/`**: Implementación y evaluación de modelos de aprendizaje automático (Machine Learning) utilizando Python y Weka, documentando el análisis de datos a través de Jupyter Notebooks.
*   **`prolog_CLIPS_Protege/`**: Desarrollo de sistemas basados en conocimiento y ontologías utilizando programación lógica y herramientas de sistemas expertos.

### 2. ⚙️ Análisis de Rendimiento y Monitorización
*   **`analisis_rendimiento_de_un_sistema_Locust_Gra/`**: Auditoría de rendimiento de un sistema simulando tráfico de usuarios concurrentes mediante `Locust`. Incluye la configuración de la telemetría y visualización de métricas en tiempo real utilizando *dashboards* de `Grafana`.

### 3. 🧠 Compiladores y Análisis Estático
*   **`analizador_lexico_Flex_Bison/`**: Construcción del *frontend* de un compilador. Implementación de analizadores léxicos y sintácticos en C utilizando `Flex` y `Bison` para procesar gramáticas formales y validar la estructura de código fuente.

### 4. 💻 Sistemas Operativos y Programación en C
*   **`creacion_de_mi_propio_bash_C/` & `programacion_comandos_bash_C/`**: Desarrollo desde cero de un intérprete de comandos (Shell) interactivo en C, gestionando procesos del sistema operativo, tuberías (*pipes*) y redirecciones de entrada/salida.
*   **`concurrencia_hilos_C/`**: Resolución de problemas de sincronización en sistemas multiproceso utilizando programación concurrente con hilos (POSIX Threads).

### 5. ☕ Desarrollo de Software y Arquitectura en Java
*   **`sistema_comunicacion_cliente_servidor_TCP_Java/`**: Diseño de una arquitectura de red robusta mediante el uso de Sockets TCP.
*   **`gestor_incidencias_interfaz_Java/` & `diagramas_sistema_gestor_incidencias_UML/`**: Ciclo de vida completo del software, desde el modelado de requisitos con diagramas UML hasta la implementación final en Java con interfaz gráfica.
*   **`creacion_para_modelado_contenedores_de_transporte_de_mercancias_java/`**: Aplicación de estructuras de datos y modelado orientado a objetos para la resolución de un problema logístico.
